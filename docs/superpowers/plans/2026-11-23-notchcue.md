# NotchCue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an offline macOS notch teleprompter that scrolls the script by matching your on-device-transcribed speech to it, with a hold-a-shortcut manual mode, so no input is needed while you read.

**Architecture:** One SwiftPM package with two parts:
- `CueCore` is pure logic with no AppKit or Speech imports. It contains the parser, normaliser, aligner, scroll maths, pace meter, vocabulary extraction and the session state machine, and holds all the unit tests.
- `NotchCue` is a thin AppKit/SwiftUI executable: the panel, settings, the speech source and the hotkeys.

`Scripts/make-app.sh` wraps the build into a signed `.app`, because mic and speech permissions need an Info.plist.

**Tech Stack:** Swift 6, SwiftPM (tools 6.2), Swift Testing, SwiftUI + AppKit, Speech (`SpeechAnalyzer`/`SpeechTranscriber`), AVFoundation, Carbon hotkeys, CoreText font registration. The toolchain is Xcode 27.2, already selected.

**Spec:** `docs/superpowers/specs/2026-11-23-notchcue-design.md`

**API reference:** Check every Apple API against https://developer.apple.com/documentation before using it, and especially these:
- `SpeechAnalyzer`, `SpeechTranscriber`, `AnalysisContext` / contextual strings, `AssetInventory`
- `NSPanel`, `NSScreen.safeAreaInsets`, `NSWindow.sharingType`
- `RegisterEventHotKey` (pressed and released events)
- `CTFontManagerRegisterFontsForURL`

Do not rely on remembered signatures.

## Global Constraints

- Deployment target is `.macOS("26.0")`, arm64 only. No third-party dependencies, no network calls in app code, no AI or LLM.
- English only: use `en-<system region>` if `SpeechTranscriber.supportedLocales` contains it, else `en-US`. There is no language picker and no `SFSpeechRecognizer` fallback.
- Native macOS look: standard SwiftUI controls, SF Symbols, system materials and colours, and grouped `Form`s like System Settings. No custom-drawn controls outside the panel.
- Bundle id is `com.saadafaq.notchcue`. App name is `NotchCue`. Use `LSUIElement = true`.
- Info.plist strings:
  - `NSMicrophoneUsageDescription` = "NotchCue listens as you read so your script scrolls by itself. Audio stays on your Mac."
  - `NSSpeechRecognitionUsageDescription` = "NotchCue recognizes speech on your Mac to keep your place in the script."
- `CueCore` must not import AppKit, SwiftUI, Speech or AVFoundation.
- Defaults:
  - text size 15 pt, line spacing 2 pt
  - panel 520×140 px
  - reading line at 30% of panel height
- Ranges: text size 12–40, width 300–900, height 80–400.
- Hide from capture on by default.
- Countdown on (3 s). Start-on-first-words off. Control `.voice`.
- Hold speed 140 wpm (60–260). Target pace 150 wpm (100–200).
- Show timer on, show pace on, pause on hover on.
- Shortcuts:
  - ⌃⌥⌘P Start/Pause
  - ⌃⌥⌘R Restart from Beginning
  - ⌃⌥⌘H Show/Hide Prompter
  - hold ⌃⌥⌘↓ to scroll (⌃⌥Space is avoided: it is the system's "Select next input source")
- UI copy uses exactly the strings in the spec's "UI copy" section: title case for menus and buttons, sentence case for settings labels, no exclamation marks.
- Script file is `~/Library/Application Support/NotchCue/script.txt`.

## Review Focus

1. **Ad-libbing or off-script chatter.** Position holds and never drifts on a stray common word. Test: `adLibDoesNotAdvance` (Task 3).
2. **Same phrase twice in the script.** The tracker picks the nearer occurrence. Test: `repeatedPhrasePicksNearest` (Task 3).
3. **Permission denied or speech model missing.** A clear message, no crash, and a retry is possible. Test: `sourceErrorMovesToErrorState` (Task 5).
4. **The hold shortcut auto-repeats while held.** Repeated "pressed" events must not stack speed or restart anything. Test: `holdBeganTwiceIsIdempotent` (Task 5).
5. **"Okay, recording now…" before the script starts, with start-on-first-words on.** Nothing moves and the timer doesn't start until the opening words are heard. Test: `waitsForFirstWordsBeforeRunning` (Task 5).

### Task 3: Script aligner

**Files:**
- Create: `Sources/CueCore/ScriptAligner.swift`, `Sources/CueCore/Fuzzy.swift`
- Test: `Tests/CueCoreTests/AlignerTests.swift`

**Interfaces:**
- Consumes: `Script.spoken`
- Produces:
  - `public struct AlignerConfig: Sendable`, with `tail = 6`, `lookahead = 30`, `lookbehind = 15`, `similarity = 0.8`, and `static let standard`
  - `public struct ScriptAligner: Sendable`, with:
    - `public init(spoken: [String], config: AlignerConfig = .standard)`
    - `public private(set) var position: Int`, the next expected spoken token, 0...count
    - `public var isFinished: Bool`
    - `public mutating func ingest(_ heard: [String]) -> Int`
    - `public mutating func reset(to: Int = 0)`, which clamps to 0...count

**Algorithm:**

```
fuzzyEqual: a == b; if min(len) <= 3 only exact; else 1 - levenshtein/maxLen >= similarity.
ingest(heard):
  t = last `tail` tokens of heard; empty → return position
  for e in max(1, position - lookbehind) ... min(count, position + lookahead):
     require fuzzyEqual(t.last, spoken[e-1])                     // anchor
     score = fuzzy-LCS length(t, spoken[max(0, e-tail-2) ..< e])
     d = e - position; need = d < 0 ? 4 : d == 1 ? 1 : d <= 8 ? 2 : 3
     score 1 counts only if the anchor token length >= 4          // stop-word guard
     score >= need → candidate
  best = max score, then min |d|, then forward; position = best.e
```

### Task 5: Prompter session

**Files:**
- Create: `Sources/CueCore/TranscriptSource.swift`, `Sources/CueCore/PrompterSession.swift`
- Test: `Tests/CueCoreTests/SessionTests.swift`, which includes `FakeTranscriptSource` (yields scripted events and records calls)

**Interfaces:**
- Consumes: `Script`, `ScriptAligner`, `TextNormalizer`, `PaceMeter`, `Vocabulary`
- Produces:
  - `public struct TranscriptEvent: Sendable, Equatable { public let text: String; public let isFinal: Bool }`
  - `public protocol TranscriptSource: Sendable { func events(vocabulary: [String]) async throws -> AsyncThrowingStream<TranscriptEvent, Error>; func stop() async }`
  - `public enum ControlMode: String, Sendable, CaseIterable { case voice, hold }`
  - `public struct SessionOptions: Sendable, Equatable`, with:
    - `countdownSeconds = 3`, where 0 means off
    - `startOnFirstWords = false`
    - `mode: ControlMode = .voice`
    - `holdWordsPerMinute = 140.0`
  - `public enum PrompterState: Equatable, Sendable { case idle, countingDown(Int), waitingForFirstWords, running, paused, finished, error(String) }`
  - `@MainActor @Observable public final class PrompterSession`, with:
    - init: `public init(source: TranscriptSource, now: @escaping () -> Date = Date.init, sleep: @escaping @Sendable (Duration) async -> Void = { try? await Task.sleep(for: $0) })`
    - `public var options: SessionOptions`
    - state: `public private(set) var script: Script`, `state: PrompterState`, `currentWordIndex: Int`, `elapsed: TimeInterval`, `wordsPerMinute: Double?`, `timeLeft: TimeInterval?`, `isHolding: Bool`
    - methods: `load(_:)`, `start() async`, `pause() async`, `resume() async`, `toggle() async`, `restart() async`
    - `resume()` goes from `.paused` straight back to `.running` (or `.waitingForFirstWords` if that hadn't been satisfied). It never replays the countdown and keeps the position. `toggle()` uses `resume()` when paused.
    - hold: `public func holdBegan() async`, `public func holdEnded()`, `public func tick()`
- Rules:
  - **Hypothesis:** keep the last 12 finalised words, and heard = `finalizedTail + words(event.text)`.
  - **Vocabulary:** `start()` passes `Vocabulary.terms(in: script)` to `events(vocabulary:)`.
  - **Countdown:** emits `.countingDown(n)` for n = countdownSeconds…1, calling `sleep(.seconds(1))` between steps.
  - **Start-on-first-words:** after the countdown, the state is `.waitingForFirstWords` (listening) until the aligner first advances; then it is `.running`.
  - **Elapsed** accumulates only in `.running`.
  - **Hold mode:** `start()` never calls the source and goes straight to `.running` after the countdown. `holdBegan()` in `.idle` calls `start()` with no countdown.
  - **Hold position:** while `isHolding`, each `tick()` advances a fractional spoken position by `wpm/60 × dt` (dt taken from `now()`).
  - **Releasing in voice mode:** `holdEnded()` calls `aligner.reset(to: Int(holdPosition))`, and voice tracking resumes from there.
  - **Clearing heard words:** the finalised tail is cleared on `holdEnded()`, `restart()` and `load()`. Transcript events that arrive while `isHolding` are dropped.
  - **`tick()`:** also refreshes `elapsed`, `wordsPerMinute` and `timeLeft` from `now()`. The panel calls it 4× per second in `.running` and `.waitingForFirstWords`, and every frame while holding.
  - **Pace:** after each position change, call `PaceMeter.record(position:at: elapsed)`.
